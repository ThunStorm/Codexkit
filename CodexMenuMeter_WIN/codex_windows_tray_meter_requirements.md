# Codex Windows 11 托盘额度计量器需求

## 已确认范围

- 所有代码、文档、测试和产物均位于 `CodexMenuMeter_WIN`。
- 只在 Microsoft Store 安装的官方 Codex 桌面应用运行时显示；终端 CLI 不触发图标。
- 托盘图标以粗体大号整数显示剩余额度，格式为 `69`，不显示 `%`；优先 5 小时窗口，无该窗口时回退到一周窗口。
- 数据缺失或认证失败时显示 `--`，不得用模拟值、缓存猜测或私有文件补齐。
- 首次运行默认注册当前用户登录启动，可在菜单开关。
- 点击菜单展示额度类型、重置时间、更新时间、任务可用性，以及打开 Codex、刷新和退出。

## 状态颜色

- 红：任务等待授权、等待输入或系统错误。
- 黄：任务运行中。
- 绿：本进程确实观察到任务从活动变为无活动；不代表任务成功。
- 灰：未知或接口不可用。

任务颜色只有在官方接口能观察到真实桌面任务时才能启用。2026-08-08 实机验证未满足该条件，因此菜单不展示任务行。设置中的“显示任务状态点（预留功能）”默认关闭；开启后仅显示灰点。

图标必须按任务栏 DPI 选择最接近的原生尺寸，数字使用 Segoe UI Bold 并以约 1.25 倍纵向比例增强，在不裁切的前提下占满可用区域。右键菜单和设置窗口使用 Per-Monitor V2 原生缩放。

## 隐私边界

只允许使用官方 `codex app-server` 的账户额度和线程摘要接口。不得读取登录凭据、SQLite、会话 JSONL、提示词、命令、路径、diff、输出或进程内存。
