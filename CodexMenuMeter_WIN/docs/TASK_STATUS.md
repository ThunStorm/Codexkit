# 桌面任务状态可行性结论

结论：当前版本不启用桌面任务状态，托盘颜色保持灰色，菜单不展示任务行。

2026-08-08 在 Windows 11、官方 Codex 桌面应用运行且存在真实活动任务时测试：

- 桌面自身的 App Server 是 `ChatGPT.exe` 的私有 stdio 子进程，没有可复用的公开连接地址。
- 另启官方 `codex app-server --listen stdio://` 后，`thread/list` 的 `sourceKinds: ["appServer"]` 返回 0 个桌面任务。
- 独立 CLI 登录态也与桌面登录态隔离。

因此不能可靠区分运行、等待授权、结束或失败。程序没有读取本地数据库、会话日志、桌面凭据或进程内存来绕过该限制。未来只有在官方提供共享且受支持的桌面任务接口，并通过真实活动任务的开始/结束验收后，才启用红/黄/绿规则。
