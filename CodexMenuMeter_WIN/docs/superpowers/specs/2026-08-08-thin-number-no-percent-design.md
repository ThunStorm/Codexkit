# Windows 托盘细数字无百分号设计

## 目标

托盘图标只显示剩余额度整数或 `--`。数字使用 `Arial Narrow` 常规字重和单色网格提示，并占用除可选灰色状态点外的最大原生像素区域；托盘图标不绘制 `%`，透明图标中不使用 ClearType。

## 保持不变

- 悬停提示和右键菜单仍以 `69%` 表达额度，避免语义不清。
- 继续按任务栏 DPI 选择 16/20/24/32/40/48/64px 中最近的原生尺寸。
- 状态点默认关闭，开启时仍只显示灰色预留点。
- 未知额度显示 `--`，真实接口、刷新和进程检测逻辑不变。

## 验证

- 先让测试要求百分号区域为空、数字覆盖完整可用区域且可见像素无 ClearType 彩边，再修改生产代码。
- 运行全部单元测试、干净构建，并替换 `dist\CodexMenuMeter.exe`。
- 真实额度仍只来自官方 App Server，不使用模拟值。
