# Windows 托盘数字与 DPI 清晰度优化设计

> 历史设计：已由 [Windows 托盘细数字无百分号设计](2026-08-08-thin-number-no-percent-design.md) 取代。

## 目标

提高 Windows 11 托盘额度数字和右键菜单的可读性，并像 macOS 版本一样保留可开关的任务状态圆点。任务数据源仍未接入，不显示或推测任务状态。

## 托盘显示

- 有额度时显示大号整数和右下角清晰下标 `%`，例如 `39` 加右下 `%`。
- 额度不可用时显示 `--`。
- 数字使用窄体粗体并作为视觉主体；`%` 使用整数像素方点和阶梯斜线，固定在右下角，尺寸不低于图标高度的约 35%，不得与数字重叠或被裁切。
- “显示任务状态点（预留功能）”默认关闭。关闭时数字使用除右下 `%` 外的最大区域；开启时左上角显示尽可能大的灰色圆点，数字使用圆点与 `%` 之间的剩余区域。
- 当前版本圆点只能为灰色。不得提供红、黄、绿手动选择，也不得根据不可见的桌面任务推测颜色。

## 设置与菜单

- 右键菜单删除“任务：状态未知（当前 Codex 桌面版未共享任务状态）”及任务行。
- 右键菜单增加“设置…”入口。
- 设置窗口提供：
  - “显示任务状态点（预留功能）”复选框，默认关闭；
  - “随 Windows 登录启动”复选框，沿用现有启动项实现；
  - 说明文字：“任务状态数据源尚未接入。开启后仅显示灰色预留点。”
  - 保存和取消按钮。
- 圆点开关保存在 `HKCU\Software\CodexMenuMeter`，保存后立即刷新托盘图标。

## DPI 与渲染

- 为可执行文件嵌入 Windows application manifest，在 WinForms 创建任何控件前声明 Per-Monitor V2 DPI 感知。
- 每次额度或设置变化时读取任务栏 DPI，从 16、20、24、32、40、48 和 64 像素中选择最接近的尺寸，再把该尺寸 HICON 交给 `NotifyIcon`。
- 每个尺寸单独排版和栅格化，不能先画一张大图再整体缩放。
- 数字使用 GDI `TextRenderer` 和像素提示字体逐尺寸绘制，采用 `NoPadding` 测量；`%` 使用整数像素方点和阶梯斜线。删除 `GraphicsPath.AddString` 和一像素描边，避免 16 像素下描边侵占字形并产生灰边。
- 前景色按 Windows 系统任务栏明暗主题选择黑或白；不使用描边补偿对比度。
- 圆点、数字和 `%` 的尺寸与每个 ICO 帧成比例并对齐到整数像素。
- 右键菜单和设置窗口使用系统菜单字体与 WinForms 原生 DPI 缩放，不使用位图缩放字体。
- DPI 查询失败时回退到系统小图标尺寸，再归一到最近的受支持尺寸。

## 数据与错误处理

- 额度来源、刷新周期、失效规则及只在官方 Codex 桌面版运行时显示的规则保持不变。
- 设置读取失败时采用安全默认值：状态点关闭；启动项读取失败只影响该复选框，不影响额度显示。
- 旧系统缺少按窗口 DPI 查询接口时仍使用系统小图标尺寸。

## 验证

- 先新增失败测试，验证显示模型把 `39` 与 `%` 分开、未知额度为 `--`、16/20/24/32/40/48/64 帧完整、右下 `%` 与数字不重叠且不越界，以及状态点默认关闭和持久化规则。
- 验证右键菜单模型不再包含任务状态行。
- 干净构建并运行全部现有测试。
- 在 Windows 11 实机分别检查状态点关闭和开启：数字、右下 `%`、圆点无裁切，16 像素帧不发灰，右键菜单字体边缘清晰。
- 对每个 ICO 帧生成放大像素探针并记录尺寸；不得使用模拟额度冒充真实接口数据。

## 不在本次范围

- 获取桌面任务状态；
- 手动选择红、黄、绿；
- 修改额度协议、登录方式或任务状态可行性结论；
- 引入第三方 UI、图标或 DPI 库。
