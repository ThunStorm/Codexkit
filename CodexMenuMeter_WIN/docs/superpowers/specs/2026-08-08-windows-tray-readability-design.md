# Windows 托盘数字与 DPI 清晰度优化设计

## 目标

提高 Windows 11 托盘额度数字和右键菜单的可读性，并像 macOS 版本一样保留可开关的任务状态圆点。任务数据源仍未接入，不显示或推测任务状态。

## 托盘显示

- 有额度时只显示整数，例如 `39`；删除 `%`。
- 额度不可用时显示 `--`。
- 数字使用窄体粗体，根据实际托盘图标尺寸动态测量，在不裁切的前提下占满可用区域。
- “显示任务状态点（预留功能）”默认关闭。关闭时数字居中并使用完整区域；开启时左上角显示尽可能大的灰色圆点，数字使用剩余区域。
- 当前版本圆点只能为灰色。不得提供红、黄、绿手动选择，也不得根据不可见的桌面任务推测颜色。

## 设置与菜单

- 右键菜单删除“任务：状态未知（当前 Codex 桌面版未共享任务状态）”及任务行。
- 右键菜单增加“设置…”入口。
- 设置窗口提供：
  - “显示任务状态点（预留功能）”复选框，默认关闭；
  - “随 Windows 登录启动”复选框，沿用现有启动项实现；
  - 说明文字：“任务状态数据源尚未接入。开启后仅显示灰色预留点。”
  - 保存和取消按钮。
- 圆点开关保存在 `HKCU\Software\CodexMenuMeter`，保存后立即刷新托盘图标。

## DPI 与渲染

- 为可执行文件嵌入 Windows application manifest，在 WinForms 创建任何控件前声明 Per-Monitor V2 DPI 感知。
- 使用任务栏窗口的 DPI 和 `GetSystemMetricsForDpi(SM_CXSMICON, dpi)` 获取托盘目标尺寸，不再固定绘制 64×64 后交给 Windows 缩小。
- 每次额度或设置变化时直接按目标像素尺寸绘制图标；任务栏 DPI 变化后下一次轮询重新生成。
- 图标文字使用像素单位、抗锯齿网格对齐和测量后居中；圆点尺寸与图标尺寸成比例并对齐到整数像素。
- 右键菜单和设置窗口使用系统菜单字体与 WinForms 原生 DPI 缩放，不使用位图缩放字体。
- 若任务栏 DPI 查询失败，回退到 `SystemInformation.SmallIconSize`，保持可用而不猜测固定缩放比例。

## 数据与错误处理

- 额度来源、刷新周期、失效规则及只在官方 Codex 桌面版运行时显示的规则保持不变。
- 设置读取失败时采用安全默认值：状态点关闭；启动项读取失败只影响该复选框，不影响额度显示。
- DPI API 在旧系统不可用时使用系统小图标尺寸，不导致程序退出。

## 验证

- 先新增失败测试，验证 `TrayText.Format(39) == "39"`、未知额度为 `--`、图标布局在有无圆点时均不越界，以及状态点默认关闭和持久化规则。
- 验证右键菜单模型不再包含任务状态行。
- 干净构建并运行全部现有测试。
- 在 Windows 11 实机分别检查状态点关闭和开启：数字、圆点无裁切，右键菜单字体边缘清晰。
- 在当前任务栏 DPI 下截图并记录生成图标的目标像素尺寸；不得使用模拟额度冒充真实接口数据。

## 不在本次范围

- 获取桌面任务状态；
- 手动选择红、黄、绿；
- 修改额度协议、登录方式或任务状态可行性结论；
- 引入第三方 UI、图标或 DPI 库。
