# Windows 托盘加粗锐利数字设计

## 目标

托盘图标继续只显示额度整数或 `--`，不显示 `%`。数字从 `Arial Narrow` 常规字重改为粗体，提高 16px 任务栏中的可辨识度。

## 渲染约束

- 保留 `TextRenderingHint.SingleBitPerPixelGridFit`，只产生单色整数像素。
- 不使用 ClearType、抗锯齿、描边、阴影或二次缩放。
- 继续按任务栏 DPI 选择 16/20/24/32/40/48/64px 中最近的原生尺寸。
- 数字继续占满除可选灰色状态点外的可用区域。

## 验证

- 先新增失败测试，明确生产渲染器使用粗体。
- 保留无 `%`、无彩色边缘和多尺寸测试。
- 生成 16px 放大像素探针，确认笔画更粗且边缘仍为单色像素。
- 干净构建、替换 `dist\CodexMenuMeter.exe` 并核对 SHA-256。
